## 📦 Local Development

To run locally:
1. Clone the repository:
   ```bash
   git clone https://github.com/Lalit05Hadkar/portfolio.git
   ```
2. Open `index.html` in any browser or run a local static server:
   ```bash
   npx serve .
   ```
